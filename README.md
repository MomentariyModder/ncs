# NaoCraftLab Community Server (NCS) 
приватный модовый проект, доступ к которому осуществляется через систему анкетирования.
Гриферство и читерство строго запрещены.
Сборка сервера: Техномагия - NeoForge 1.21.1
📋 Основные требования:
• Быть адекватным, дружелюбным к другим участникам сервера, не нарушать правила.
• Быть старше 13 лет
